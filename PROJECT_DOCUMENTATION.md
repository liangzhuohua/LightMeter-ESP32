# ESP32-S3 胶卷相机测光表项目文档

## 项目概述

本项目是一个基于 **ESP32-S3N16R8** 的专业胶卷相机测光表，具备入射式测光、曝光计算、WiFi联网同步、天气显示和OTA升级等功能。采用460x460分辨率AMOLED触摸屏，配合LVGL图形库构建用户界面。

---

## 一、功能总结

### 1.1 核心测光功能
- **入射式测光**：使用VEML7700环境光传感器测量环境光照度
- **曝光计算**：支持光圈优先、快门优先、全自动三种模式
- **场景模式**：
  - 手动模式 (MANUAL)：用户完全控制光圈和快门
  - 自动模式 (AUTO)：根据光照自动计算最佳曝光组合
  - 风光模式 (LANDSCAPE)：优先使用f/11小光圈保证景深
  - 人像模式 (PORTRAIT)：优先使用最大光圈获得浅景深

### 1.2 相机/镜头管理
- 支持多相机配置，记录相机快门范围和闪光同步速度
- 支持多镜头配置，记录光圈范围和焦距
- 支持1/3档和1/2档步进
- 相机/镜头参数用于曝光计算时的范围限制和警告

### 1.3 网络功能
- **WiFi连接**：支持保存多个WiFi配置，自动连接
- **自动定位**：使用WiFi BSSID定位，自动获取经纬度和城市信息
- **时间同步**：SNTP自动同步时间，根据经度自动计算时区
- **天气显示**：通过和风天气API获取当前天气、温度、湿度、日出日落、月相等信息
- **OTA升级**：AP热点模式支持浏览器上传固件升级

### 1.4 电源管理
- **电池监测**：MAX17055电量计实时监测电池电量、电压、电流
- **深度休眠**：长按按键3秒进入深度休眠，释放所有外设引脚防止漏电
- **RTC时间保持**：休眠时时间保存在RTC中，唤醒后恢复

### 1.5 用户界面
- **触摸交互**：电容触摸屏支持滑动和点击操作
- **滚轮选择器**：快速选择ISO、光圈、快门、EV补偿值
- **T9键盘**：输入相机和镜头名称
- **状态显示**：实时显示WiFi信号、电池电量、光照强度
- **指示图标**：定位、天气、时间同步状态指示

### 2.5 曝光计算算法

#### 核心公式
```
入射光测光公式:
EV = log2(Lux / K) + log2(ISO / 100)
其中 K = 2.5 (校准常数)

光圈优先模式:
快门 = 光圈² / 2^EV

快门优先模式:
光圈 = sqrt(2^EV × 快门)
```

#### 曝光状态标志
```c
typedef struct {
    uint8_t aperture_out_of_range : 1;  // 光圈超出镜头范围
    uint8_t shutter_out_of_range : 1;   // 快门超出相机范围
    uint8_t overexposure : 1;           // 过曝警告
    uint8_t underexposure : 1;          // 欠曝警告
    uint8_t slow_shutter_warning : 1;   // 快门过慢警告
} ExposureFlags;
```

#### 档位表
- **光圈表**：支持1/3档和1/2档步进，范围f/1 ~ f/64
- **快门表**：支持1/3档和1/2档步进，范围1/8000s ~ 30s
- **ISO表**：ISO 6 ~ ISO 12800

### 2.6 NVS存储结构

| 命名空间 | 存储内容 |
|----------|----------|
| `camera` | 相机配置(快门范围、步进类型、闪光同步) |
| `lens` | 镜头配置(光圈范围、焦距、自定义光圈) |
| `ui_state` | UI状态(ISO、EV、模式、选中索引) |
| `wifi` | WiFi配置(SSID、密码、启用状态) |
| `location` | 位置信息(经纬度、城市、详细地址) |
| `weather` | 天气缓存 |
| `sync_ts` | 同步时间戳 |

### 2.7 网络API

#### 定位服务
- API: `http://api.cellocation.com:84/wifi/`
- 方法: 使用WiFi BSSID定位
- 返回: 经纬度、城市、详细地址

#### 时间同步
- SNTP服务器: `pool.ntp.org`, `cn.pool.ntp.org`, `ntp1.aliyun.com`
- 时区: 根据经度自动计算

#### 天气服务
- API: 和风天气
- 数据: 温度、湿度、风速、日出日落、月出月落、月相
